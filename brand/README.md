# Brand assets

**The files in this directory are not covered by the licences in [`../LICENSING.md`](../LICENSING.md).**
They are the TigerTag and TigerSystem logos, copied unmodified from the TigerTag protocol
repository, where their terms live:
[TigerTag-RFID-Guide/brand](https://github.com/TigerTag-Project/TigerTag-RFID-Guide/tree/main/brand).

| File | Use on |
|---|---|
| `logo_tigertag_contouring_head.svg` | White and light backgrounds (the black, contoured logo) |
| `logo_tigertag_head.svg` | Dark backgrounds only (the white logo) |
| `tigersystem-icon-framed.svg` | The site's favicon: the TigerSystem icon in its own frame |
| `tigersystem-apple-touch-icon.png` | The site's touch icon |

On a light background the contoured (black) logo, on a dark one the white logo: the README picks
one with `prefers-color-scheme`, the reference site with its theme.
