# Examples

The nine TigerQR formats of one Filament Label, as Tiger Studio exports them (SVG, sized in
millimetres, drawn for 300 dpi): Polymaker Panchroma Gradient Silk Fire, `id_product` 27996997.
Every QR reads `https://qr.tigertag.io/p/0027996997`; every pill reads TigerQR+.

The same label for any catalogue product, in any format and at 203 or 300 dpi:
`https://tigersystem.io/api/public/v1/label/<id>.svg?template=<format>&dpi=<203|300>`.
